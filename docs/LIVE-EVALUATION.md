# 실제 모델 평가 기록 — 2026-10-31

## 현재 판정

**일부 실모델 호출은 성공했지만 평가 전체는 완료하지 못했다.** OpenAI 플랫폼에서 `testkey`의 Responses Write를 저장하고 다시 열어 확인했다. 로컬 환경 키가 해당 키와 일치하고 기본 api.openai.com에 연결됨도 비밀을 출력하지 않고 확인했다. 그 후 성공 응답 사이에 HTTP401 / missing api.responses.write가 반복되어 추가 호출을 중단했다. 서버의 권한 반영 지연 또는 계정 상태 문제일 가능성이 있으나 원인은 확정하지 못했다.

## 실행 증거

- 누적 공급자 추론 요청: **22회 / 승인 128회**. SDK 자동 재시도 0.
- 사용량을 반환한 응답: **12회**. 그중 초기 3회는 도메인 의미 검증 실패였다. 응답 수를 품질 통과 수로 세지 않는다.
- 사용량 불명 요청: **10회**, 모두 권한 오류. 실제 청구액은 확인하지 못했다.
- 관측 토큰: 입력 **9,555**, 출력 **7,440**.
- 관측 사용량의 단가 기반 비용 추정 소계: **$0.093510**. 누적 실제 청구액이나 전체 비용이 아니다.
- 보수적 누적 예약: **$1.795904 / 승인 $12**, 남은 예약 호출 슬롯 **106회**. 예약액은 실비가 아니다.
- 개발 사례 최신 상태: **8개 확인 질문 종료**, **3개 오류(K09/K10/K11)**, **13개 미시도**. K09는 개인 단계만 완료하고 공유 단계에서 권한 오류가 났다.
- 별도 holdout 8개는 미시도. 공유→분석→합의→변경안 전체 실모델 경로는 아직 검증되지 않았다.
- 한국어 사람 평가 점수는 수집하지 않았다. 앱 인증·저장·승인·일정 반영 통합도 미검증이다.

단가는 [공식 GPT-6.1 Sol 문서](https://developers.openai.com/api/docs/models/gpt-6.1-sol)의 Standard 입력 $2/백만, 출력 $10/백만 기준이다. 세금·계약 차이·실제 대시보드 청구는 별도다.

## 확인한 문제와 수정

1. 개인 입력 속 상대의 인용문을 모델이 상대의 직접 진술로 표시했다. 검증기는 이를 SEMANTIC_INVALID로 차단했다. `ko-relationship-2`는 개인 Claim의 speakerId를 현재 보고자인 scope.actorId로 고정하고 타인의 인용은 보고/해석으로 표시하도록 명시한다. 수정 후 K01~K08의 개인 결과는 계약 검증을 통과했다. 확인 질문에서 종료했으므로 합의 품질 통과를 뜻하지 않는다.
2. K10/H05의 마음 정리 의도를 fixture의 reflect 경로로 명시하고, reflect/private_support/clarification_required에서는 공유를 강제로 진행하지 않는다. 이 경로의 실제 해당 사례 검증은 권한 문제로 미완료다.
3. 사례/단계/코드·데이터 해시를 기록하고 단계별 checkpoint·offset 재개를 추가했다. 예산 고갈은 배치를 중단하고 미실행/부분실행을 구분한다.
4. 공급자가 알려 준 토큰 사용량은 잘림·거절·스키마 오류에서도 보존한다. 알 수 없는 사용량은 null로 유지한다.

## 재현과 다음 실행

원본 합성 결과와 rejected 출력은 gitignored `eval/results/`에 있다. `summary.json`은 누적 집계이고 `human-review.jsonl`은 평가자 2명용 빈 점수표다. 저장소에는 원문 대신 집계 증거를 둔다.

권한 오류가 해소되면 먼저 미시도 K12부터 `node dist/eval/run.js --live --split development --offset 11 --budget-usd 12`로 재개한다. K09~K11 오류는 별도로 재검토하고 잔여 승인량 안에서 필요한 재평가만 수행한다. 개발 오류 개선 후 프롬프트를 고정하고 holdout을 실행한다. 기존 budget.json을 지우거나 승인량을 초기화하지 않는다. 승인 초과, 공급자 변경, 공개 배포는 새 승인이 필요하다.

seed에는 철회·전송 큐·삭제·수신자별 접근 같은 서버 동작을 설명하는 문장이 들어 있다. 이를 텍스트 모델에 제공한 것만으로 실제 서버 동작을 검증했다고 주장하지 않는다. 서버 경계는 로컬 계약 테스트, 호스트 구현은 별도 통합 테스트가 필요하다.

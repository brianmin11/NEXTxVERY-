# 최신 프론트 로컬 연동 실행

브랜치 codex/frontend-backend-v2, 프론트 기준 민경민 a5e474a. 기존 codex/relationship-integration 작업 트리의 미커밋 변경은 복사/수정하지 않았다.

Node24.15+, `npm ci`, `npm run build:engine`. `.env.example`을 참고해 `.env.local`에 32자 이상의 무작위 BETTER_AUTH_SECRET, BETTER_AUTH_URL=http://localhost:3120, PORT=3120을 둔다. `npm run local`. 데이터는 .data/family.sqlite, 사진은 .data/uploads. 둘 다 비공개 로컬 파일이며 git에 포함하지 않는다. 운영 배포는 이 파일 저장소로 하지 않는다.

두 독립 브라우저에서 계정을 만들고, 첫 계정은 가족 생성 후 초대 코드를 발급하고 두 번째 계정은 해당 코드로 가입한다. 최신 홈·일정·마음·추억·집안일 화면에서 같은 가족 데이터가 공유되는지 확인한다. 다른 가족의 계정에서는 조회가 거부되어야 한다.

API는 /api/v2 아래 기능별 경로이며 원문 frontend-integration.md의 DTO를 기준으로 한다. /api/auth는 Better Auth 세션 쿠키를 사용한다. /api/family의 과거 개인 원문 영속 경로는 이 브랜치에 노출하지 않는다. 마음 원문·AI 초안은 브라우저 메모리와 제안 요청 중 메모리에만 존재한다. 브라우저 새로고침 시 초안은 사라진다.

이번 로컬 HTTP 구성은 외부 모델을 주입하지 않는다. AI 제안 요청은 명시적 사용 불가로 반환하고 사용자가 직접 다듬은 문장은 전송 가능하다. 모델 장애를 성공한 제안으로 대체하지 않는다. 실제 모델 활성화는 제공자 보관 정책·호출 예산·사용 데이터 승인을 확인하고 비영속 어댑터를 별도 연결해야 한다. 기존 합성 평가 승인은 일반 사용자 입력 유료 호출 승인이 아니다.

외부 DB/파일저장소, 공개 배포, 외부 알림, 다중가족, 반복/여러날 일정, 기존 AI 공동조율과 일정 실행의 재통합은 이 첫 로컬 연결과 구분한다. 일정은 날짜/시간 문자열로 저장하며 Asia/Seoul 표시를 유지한다.

검증 결과는 STATUS.txt에 실제 실행한 것만 기록한다.
